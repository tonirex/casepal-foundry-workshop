## Summary

A variation of a previously-registered electrical bone-growth stimulator — new indication added (spinal fusion adjunct in addition to the base long-bone non-union indication).

## Assessment

The variation involved:

- **New indication** — required updated clinical evidence for the spinal-fusion use.
- **Same core hardware** — no risk-class change, no material change to safety profile.
- **Updated labelling** — new indication reflected in IFU.

The clinical evaluation (SOP-03) for the added indication cited a moderately-sized RCT (n=148) plus two supporting observational studies. Benefit-risk quantified for the new use.

## The condition

The reviewer accepted with a **post-market clinical follow-up condition**: the applicant is required to submit an annual PMCF report covering the new spinal-fusion indication for three years, tracking:

- Effectiveness against the manufacturer's stated primary endpoint.
- Any adverse events specific to the new indication.
- Real-world usage patterns.

Failure to submit the PMCF report within 60 days of each anniversary triggers a formal query.

## Why this precedent is useful

Teaching point: **accepted with condition** is a common middle-ground outcome for variations that expand indications. CasePal should recognise this pattern — the recommendation *"accept with PMCF condition"* is a first-class output, not a fallback compromise. The Comms Drafter (Lab 4) can draft a condition letter in the same shape as an RFI.
