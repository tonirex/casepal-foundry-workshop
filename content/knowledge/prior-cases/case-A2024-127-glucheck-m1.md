## Summary

A wearable continuous glucose monitor. Class B based on the diagnostic-measurement purpose and low invasiveness (transdermal sensor).

## The query

At intake, the CER (SOP-03) referenced literature for the analytical performance claim but did not include applicant-generated precision or bias data. SOP-01 Class B §3.2 requires precision, accuracy, and repeatability data where measurement is claimed.

The RFI (drafted per SOP-05) asked for:

1. Precision study data across the claimed measurement range.
2. Bias assessment against a reference method.
3. Confirmation that any AI-driven data-smoothing component (mentioned in the software documentation) was included in the risk file.

## Response and decision

The applicant responded within 30 days with the requested precision study, a comparator-method bias table, and confirmed the smoothing algorithm was in scope of the ISO 14971 risk file (updated version submitted).

Reviewer accepted; standard Class B PMS plan.

## Why this precedent is useful

Teaching point: **queried then accepted** is the most common outcome for a Class B measurement device where the applicant simply omitted precision data. Regulatory reviewers rarely reject on first pass — they query. CasePal should present this pattern as the expected shape when a dossier is otherwise sound but missing quantified performance evidence.
