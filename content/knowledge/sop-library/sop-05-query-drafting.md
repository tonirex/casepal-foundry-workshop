# SOP-05 · Query Letter (Request For Information) Drafting Standards

**Version:** 2.0
**Owner:** Health Products Regulation Group · Medical Devices Branch
**Effective:** 1 October 2024

> **Synthetic content for the CasePal Foundry workshop.**

## 1. Purpose

Define the tone, structure, and content of Request-For-Information (RFI) query letters sent from the Agency to a medical-device applicant during dossier review.

## 2. When to send an RFI

An RFI is sent when:

- A required document is absent (per SOP-01), OR
- A submitted document is incomplete or inconsistent, OR
- Clarification is needed on risk classification, clinical evidence, or manufacturing quality.

An RFI is **not** sent for reviewer preference or opinion — only for information gaps blocking the technical review.

## 3. Structure

Every RFI must have:

1. **Subject line** — `[MDR-<year>-<seq>] Request for information` (case ID first for tracking).
2. **Greeting** — professional, addressed to the applicant's regulatory contact.
3. **Case reference paragraph** — one sentence naming the submission and its receipt date.
4. **Numbered list of specific questions** — each question:
   - references the SOP or guideline the requirement flows from,
   - names the specific missing / incomplete item,
   - describes acceptable evidence for closure.
5. **Deadline** — standard 30-calendar-day response window from receipt.
6. **Sign-off** — Reviewer's name, role, contact channel.
7. **Automated footer** — reference number, encrypted-email-only notice.

## 4. Tone rules

- **Professional and neutral.** No language implying the submission will be rejected; no language implying it will be accepted.
- **Specific, not vague.** *"Please provide the precision data for the analytical performance claim on page 32"* — not *"Your dossier is incomplete."*
- **No causality claims.** *"Data appears absent"* — not *"You forgot to include the data"*.
- **No regulatory action language.** Never write *"or your dossier will be rejected"*, *"or a recall will be issued"*. RFIs request; they do not threaten.
- **British English spelling** for consistency with existing Agency correspondence.

## 5. What CasePal produces

CasePal drafts the RFI body. The reviewer reviews, edits, adds any case-specific context, and sends. CasePal:

- Never sends the RFI directly.
- Never inserts a specific accept / reject verdict.
- Cites the SOP or guideline number for each question so the reviewer can verify the requirement is real.

## 6. Length target

4–8 sentences of body plus the numbered questions. RFI letters do not need to be long — clarity beats verbosity.
